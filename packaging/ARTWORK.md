# Artwork provenance

The Stats app icon, menu bar renderings, and asset catalog come from the [Stats v3.1.1 release](https://github.com/exelban/stats/releases/tag/v3.1.1). The source artwork is retained in `Stats/Supporting Files/Stats.icon` and `Stats/Supporting Files/Assets.xcassets`. The release build copies these generated resources to keep the upstream Stats branding consistent across versions of the Xcode asset compiler. See the repository's MIT license.
